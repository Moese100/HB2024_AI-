# 湖北2024 AI套项正式定额库

本私有仓库存放**唯一正式使用**的湖北省2024年修复版定额JSON库、全专业统一检索索引和质量标记。GitHub的 `main` 分支是版本源；本地同名文件夹是日常检索和AI套项直接使用的正式库。

> **日常原则：** 名称与项目特征匹配时优先查本JSON库；只有复杂规格、规则冲突或低置信度候选时才回查本地原始PDF。修复前旧JSON库已归档到私有仓库的 `legacy-pre-repair` 分支，仅供回退，禁止日常检索。

## 本地目录规则

将本仓库直接克隆到以下原有正式库目录：

```text
D:\desktop\Codex共享文件夹\HB2024_AI套项数据库\01_基础定额库\HB2024_Base_JSON_DB_Windows
```

克隆后，该目录本身就是正式JSON库；不需要创建第二个“数据库仓库”文件夹。其包含六个正式目录：

```text
HB2024_Base_JSON_DB_Windows
├─ 安装2024JSON
├─ 房建装饰2024JSON
├─ 公共专业2024JSON
├─ 湖北2024定额库_统一索引
├─ 市政2024JSON
├─ 园林绿化2024JSON
├─ scripts
└─ .git              （Git隐藏目录）
```

## 原始PDF保存位置

原始PDF不上传到GitHub，也不会在更新时被删除。请在基础库目录下单独保存：

```text
D:\desktop\Codex共享文件夹\HB2024_AI套项数据库\01_基础定额库\00_原始定额PDF权威底稿
```

该目录用于争议复核与后续数据库修复，不作为日常第一检索源。

## 第一次配置

由于现有目录仍有旧错误JSON，请先完成旧JSON的本地归档或移除，再将本仓库克隆到上方的正式库路径。克隆时GitHub Desktop会提示目标目录非空；请选择“保留原始PDF”等非JSON文件，但不要保留旧JSON文件作为活动库。首次操作时请按本对话指引执行，不要自行覆盖。

## 日常同步

当收到“数据库已更新”的通知后，在正式库根目录打开 `scripts` 文件夹，双击：

```text
同步最新数据库并更新本地.bat
```

脚本会先执行 `git pull --ff-only` 拉取GitHub正式版本，再核验六个JSON目录；它不会移动、删除或上传原始PDF、ZIP、规则库、GBQ样表、待处理清单或其他 `02—06` 文件夹内容。

## 版本和回退

GitHub自动保留每次正式修复的提交记录。若需要回退，可在GitHub Desktop的历史记录中选择旧版本；修复前旧JSON压缩包位于 `legacy-pre-repair` 分支的 `legacy` 目录。
