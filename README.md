# 湖北2024 AI套项数据库

本仓库存放已修复的湖北省2024年定额JSON数据库、统一检索索引和本地安全同步工具。仓库为私有仓库，仅授权账户可访问。

> **本地同步原则：** 先备份，再更新；不删除本地已有文件；定额编码、单位、基价保持不变；仅同步修复后的JSON库和索引。

## 第一次在电脑上配置

建议使用 **GitHub Desktop**，不需要在命令行输入Git命令。正式工作库和GitHub仓库副本必须分开存放。

1. 在浏览器中打开本仓库页面，点击绿色的 **Code** 按钮。
2. 选择 **Open with GitHub Desktop**；如电脑未安装该软件，按提示安装后用自己的GitHub账号登录。
3. 在“Local path（本地路径）”中选择一个**新的空文件夹**，例如：

   ```text
   D:\desktop\Codex共享文件夹\HB2024_AI套项数据库仓库
   ```

   不要直接选原有的 `HB2024_AI套项数据库` 文件夹，以免首次克隆时和旧文件混在一起。
4. 完成克隆后，打开新下载的仓库文件夹，进入 `scripts` 文件夹。
5. 双击 `一键同步到本地.bat`。脚本已固定为只更新以下正式JSON目录：

   ```text
   D:\desktop\Codex共享文件夹\HB2024_AI套项数据库\01_基础定额库\HB2024_Base_JSON_DB_Windows
   ```

6. 输入 `Y` 确认。脚本只处理六个定额JSON目录；先备份旧JSON，再写入修复版JSON。它不会删除原始PDF、ZIP、README、CSV、规则库或 `02—06` 文件夹内容。

## 以后更新数据库

当收到“数据库已更新”的通知后，只需进入本仓库的 `scripts` 文件夹，双击：

```text
同步最新数据库并更新本地.bat
```

该文件会自动完成以下操作：先从GitHub拉取最新版；再运行本地备份；最后原位更新五个专业JSON库、统一检索索引和质量标记。

## 备份和日志位置

每次同步前的旧JSON会保存至：

```text
D:\desktop\Codex共享文件夹\HB2024_AI套项数据库\01_基础定额库\.HB2024_AI旧JSON本地备份\年月日_时分秒\
```

修复前旧JSON库的ZIP同时归档在本私有仓库的 `legacy-pre-repair` 分支中，仅供回退，不能用于日常检索。

同步日志会写入数据库根目录，文件名形如：

```text
HB2024_AI数据库更新日志_20260820_120000.txt
```

如果更新后发现问题，可从对应时间戳的备份目录恢复文件，或在GitHub仓库中恢复历史版本。

## 仓库内容范围

仓库仅包含可运行的JSON数据库、全专业统一检索索引、复杂规格子目质量标记和同步工具。不会上传原始PDF、真实项目清单、GBQ结果表、价格数据或其他个人文件。
